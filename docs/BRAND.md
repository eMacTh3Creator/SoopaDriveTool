# Logo and interface assets

Developer: Ev-Tech Solutions, LLC.

The logo is an indigo drive icon with a mint lightning-shaped read/write arm. The source PNG and Windows ICO are in `src/SoopaDriveTool.Windows/Assets/`. The icon was generated for this project using an image-generation tool.

## Interface colors

| Use | Color |
|---|---|
| Text | `#15253F` |
| Navigation | `#14233E` |
| Accent | `#5355E8` |
| Secondary accent | `#28B89A` |
| Background | `#F4F6FA` |

The application uses Segoe UI Variable Text with the standard Windows font fallback.
