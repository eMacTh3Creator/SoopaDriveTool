# SoopaDriveTool implementation and qualification

This ledger tracks the expanded suite on `feature/complete-storage-suite`. Published installers remain at 0.2.1 until the new acceptance checks and packaging finish. A working interface is not counted as hardware qualification.

| Area | Implemented backend and interface | Current acceptance |
|---|---|---|
| Protected backup | AES-256-GCM/Brotli packets, encrypted manifests, full/incremental/differential generations, exclusions, locking, retention/GC, selective restore, passphrase rotation, permissions/streams/hardlinks/links, native VSS requester, DPAPI user/SYSTEM scheduling and management | Core tests pass. Stable VSS snapshot/writer/cleanup checks passed in the spare VM. Real streams, hardlinks, owner and DACL restore checked; Windows inheritance normalization fixed. Installed schedule execution and network qualification pending. |
| Disk images | Protected compressed chunked raw images, incremental/differential points, verification and read-back restore; VSS Windows WIM capture; raw read-only VHD browsing and selective WIM extraction | Core raw round trip passes. Native decoder independently reads managed encrypted/plain objects, including small files and named streams. Physical image restore, browse and Windows recovery tests in progress. |
| Migration | Inactive and live VSS Windows UEFI clone, filesystem clone, byte-exact clone, larger-target GPT relocation, fresh OS-aware identifiers, offline drive mapping, EFI/BCD and WinRE registration | 0.2.1 inactive Windows and byte clones independently booted twice. Live VSS Windows clone to a smaller owned spare disk passed two independent Secure Boot cold boots. One-time WinRE activation and protected-image recovery boot qualification are in progress. |
| Partitioning | Real overlap-safe move with durable pending chunks and reviewed resume; split/merge; shrink/move/grow redistribution; filesystem/allocation-unit migration using verified recovery WIM; nonempty GPT/MBR and primary/logical conversion; guarded basic/dynamic simple-volume conversion | Core crash fault injection passes for left/right overlapping moves and metadata commits. Real NTFS move, GPT/MBR and primary/logical round trips preserve files in the spare VM. Split, merge, redistribution and NTFS-to-exFAT data preservation pass; Unicode read-only image browse and custom DiskSpd checks pass. Basic/dynamic simple NTFS conversion passed with a final remount pending restart. |
| Recovery | Backup GPT reconstruction, lost NTFS/exFAT/FAT32 partition scan and reviewed insertion, NTFS deleted MFT/data runs, FAT32 deleted directory entries, contiguous PNG/JPEG/PDF carving, source-byte preview/export, hash-guarded sector editor | Core bounds, nonoverlap, retained original sector, stale preview, carving/export and surface tests pass. Deleted-file and reviewed recovery checks on owned Windows volumes pending. Fragmented carving, compressed/EFS NTFS recovery and multi-disk dynamic reconstruction are not claimed. |
| Diagnostics and erase | Full exported SMART/logs; device self-test requests; temperature samples/chart; read surface map/report; volume/pool/virtual-disk topology; free-space overwrite; Windows native NVMe erase; WinPE ATA erase with direct-bus, frozen/locked/security checks | Existing SMART and overwrite tests pass. New surfaces, test requests and unsupported-device paths pending. Real firmware erase requires an eligible disposable physical device; no VM result establishes firmware erasure coverage. |
| Recovery media | Native ARM64/x64 host, authenticated raw restore, Windows WIM apply/boot reconstruction, byte clone and verified overwrite; installed-ADK ISO/USB builder and signed-driver injection | Native hosts compile. Microsoft ADK and WinPE installed in spare. ARM64 Secure Boot ISO boot and native-GUI encrypted raw restore passed; complete destination hash matched independently. Windows restore boots and physical USB qualification remain in progress. Microsoft boot files are not bundled in public installers. |
| Benchmarking | Standard and custom block/queue/thread/read-percent workloads; random/zero data, profile save/load, exports, historical throughput comparison charts, device temperature history | Existing native DiskSpd tests pass. Custom workload and comparison checks pending. |
| Usability | Task tabs, disk maps, apply queue, measured/indeterminate activity, waiting facts toggle, journals and interrupted-run detection, light/dark/system themes, compact layout, labeled input controls | Windows compilation passes; all 10 workspaces render; light/dark contrast and keyboard checks are being finalized. Interface instructions are English. |
| Release | Native components and licenses integrated into package build; ARM64/x64 installers and portable packages | New source has not yet been released. Full tests, package install/upgrade/uninstall, CI, new documentation, site and release receipts remain required. Unsigned builds must remain labeled as such. |

Supported conversions and recovery modes enforce their filesystem/device constraints before writing. A submitted SMART self-test is not a health pass, a controller erase completion is not a certified purge, and a captured Windows image is not considered boot-qualified until the restored disk is independently booted.
