What is included?

Advanced partition management, dependent action chains, live and inactive Windows cloning, byte/used-file cloning, encrypted file and Windows-image backups, native recovery media, deleted-file tools, quick/thorough wiping, custom benchmarks, full available SMART exports and detailed activity.

What does recovery media need?

Install Microsoft's Windows ADK Deployment Tools and matching WinPE add-on. SoopaDriveTool builds an architecture-matched ISO with its native recovery app and selected signed drivers. Microsoft boot files come from your ADK installation. Boot-test the media with your storage before relying on it.

Which conditions matter?

Partition changes protect running Windows and reject BitLocker or unknown encryption. Used-file migration needs scratch space. Dynamic conversion supports eligible contiguous simple NTFS volumes. Recovery depends on surviving filesystem data; fragmented carving and encrypted/compressed NTFS recovery are outside supported modes. Quick reset leaves file data recoverable.

How is it qualified?

Disposable-disk tests, independent ARM64 Windows clone and image-restore boots, encrypted recovery checks, native ARM64/x64 builds and installer checks are recorded in the validation report. Installers are unsigned. Physical firmware erase, x64 recovery boots, USB bridges and full assistive-technology coverage need additional hardware qualification. Controller completion is not a certified purge.
