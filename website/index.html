What works in this preview?

Data-disk action chains, real benchmarks, file snapshots, raw and used-file cloning, Windows-aware UEFI setup for inactive installations, quick/thorough wiping, full available SMART exports and live activity.

What is still planned?

Partition moving/merging, cloning the currently running OS, VSS-consistent system backups, encrypted image containers, deleted-file recovery and a separately qualified WinPE recovery environment. Full Windows-aware and byte-exact clones have passed independent ARM64 VM boots. x64 OS boot and physical hardware remain unqualified.

What should I know before using it?

Installers are unsigned. Disk operations cannot automatically roll back after apply. Byte-exact clones/restores require offline data disks and matching disk/sector sizes. WIM clone modes use mounted, unencrypted NTFS sources and separate scratch storage. Backups are unencrypted; file snapshots do not preserve all NTFS metadata. Quick reset leaves data recoverable. Overwrites are not firmware SSD sanitize. Keep independent backups.

How is it tested?

Independent Windows-aware and byte-exact ARM64 clone boots with the source disconnected, plus automated policy/backup/parser tests, disposable-disk integration, native ARM64/x64 builds and installer checks. See the validation report for exact results. Physical hardware and interactive accessibility qualification remain outstanding.
