What works in this preview?

Data-disk partition operations, real benchmarks, compressed file snapshots, verified offline raw images and equal-size clones, zero-overwrite, MBR/GPT image inspection, controller health counters and local journals.

What is still planned?

Partition moving/merging, smaller-target OS migration, VSS-consistent system backups, encrypted image containers, deleted-file recovery, boot repair and a separately qualified WinPE recovery environment.

What should I know before using it?

Installers are unsigned. Disk operations cannot automatically roll back after apply. Raw tools require offline data disks and matching disk/sector sizes. Backups are unencrypted; file snapshots do not preserve all NTFS metadata. Zero-overwrite is not SSD secure erase. Keep independent backups.

How is it tested?

Automated policy, backup, parser and benchmark tests; disposable virtual-disk integration tests; native ARM64 VM validation; x64 Windows CI; and installer checks. See the validation report for exact results. Physical hardware and interactive accessibility qualification remain outstanding.
